# React Learning Projects

This repository contains several small React example projects and exercises collected for learning and demo purposes.

Projects included:
- 01basicapp: Create React App example
- 01basicvite: Vite + React example
- 02project, 03project, 04project: additional Vite-based sample projects
- colchanger: color changer demo
- passgen: simple password generator
- costomreact: small custom script example

Quick start
1. Clone the repo:
   git clone git@github.com:jashwanthrv/react_leanr.git
2. Open a project folder (for example `01basicvite`), then install dependencies and run:
   cd 01basicvite
   npm install
   npm start

Notes
- Each subproject is self-contained. Run install/start inside the project you want to view.
- A .gitignore has been added to ignore common Node and IDE files.
